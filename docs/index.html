Features

What it does

AkiLink is a modern WPF desktop application that uses the WinRT AudioPlaybackConnection API to receive streaming audio from paired Bluetooth devices — phones, tablets and more. One-click connect with real-time status, full codec settings, auto-reconnect and tray-resident operation, backed by 75 passing unit tests.

📶

Device discovery & one-click connect

Scans paired Bluetooth audio devices and establishes or tears down the connection in a single click, with real-time status for connected, disconnected and error states.

🎚️

Codec settings

Preferred codec (Auto / SBC / AAC / aptX / LDAC), bitrate up to 990 kbps, 44.1 or 48 kHz sample rates, and Balanced / Best Quality / Low Latency transmission modes.

🔁

Auto-reconnect

Automatically reconnects when the paired device comes back in range, with an optional auto-connect to the last device at startup.

🔊

Volume control

Master volume slider plus mute toggle, kept in sync with Windows system audio.

📌

System tray & compact mode

Minimize to tray so audio continues in the background, with balloon alerts on connect and unexpected disconnect. A minimal always-on-top overlay covers monitoring.

🕘

Connection history

A full log of connect, disconnect and error events with per-entry delete and clear support.

🪟

Start with Windows

An optional auto-launch toggle registers a user-level registry entry — no elevation needed, applies instantly, and can be disabled from Settings or Task Manager.

🌐

Bilingual, dark & glassy

English and 中文 UI languages switchable at runtime, in a modern dark theme with card-style layout following the Ethereal Glass design language.

Quick Start

Build from source

  1. Requirements — Windows 10 (build 19041+) or Windows 11, a Bluetooth adapter with audio playback support, and the .NET 10 SDK.
  2. Build and run with dotnet build and dotnet run, or run the test suite with dotnet test.
  3. Or download the installer, the self-contained exe, or the portable zip from Releases.
  4. Connect — scan your paired devices and click connect; your phone's audio now plays through the PC.
shell
# Build
dotnet build

# Run
dotnet run

# Test
dotnet test

项目简介

AkiLink 是一款现代化的 WPF 桌面应用，通过 WinRT AudioPlaybackConnection API 接收来自已配对蓝牙设备（手机、平板等）的流式音频。一键连接、实时状态、完整的编码设置、自动重连与托盘常驻，75 个单元测试全部通过。

📶

设备发现与一键连接

扫描已配对的蓝牙音频设备，单击即可建立或断开连接，已连接 / 已断开 / 错误状态实时可见。

🎚️

音频编码设置

首选编码（自动 / SBC / AAC / aptX / LDAC）、比特率最高 990 kbps、44.1 或 48 kHz 采样率，以及均衡 / 最佳音质 / 低延迟传输模式。

🔁

自动重连

设备回到范围内时自动重新连接，并支持启动时自动连接上次的设备。

🔊

音量控制

主音量滑块加静音切换，与 Windows 系统音频保持同步。

📌

系统托盘与精简模式

最小化到托盘，音频持续播放；连接与意外断开时弹出气泡提示。精简浮窗始终置顶，方便随时监控。

🕘

连接历史

完整的连接 / 断开 / 错误事件日志，支持逐条删除与清空。

🪟

开机自动启动

可选的自启动开关写入用户级注册表项——无需管理员权限，即时生效，可随时在设置或任务管理器中关闭。

🌐

双语、深色与玻璃质感

英文与中文界面运行时一键切换，深色主题卡片式布局，延续 Ethereal Glass 设计语言。
